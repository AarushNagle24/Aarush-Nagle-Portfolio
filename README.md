# Aarush Nagle Portfolio

Static GitHub Pages portfolio for Aarush Nagle.

## Local Preview

Open `index.html` in a browser, or serve the folder with any static file server.

```powershell
python -m http.server 8000
```

## GitHub Pages

This site is ready to publish from the repository root.

1. Push the repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Set the source to the `main` branch and `/root`.
5. Save.

The expected Pages URL for this repository is:

```text
https://aarushnagle24.github.io/Aarush-Nagle-Portfolio/
```
